Please download the dump data of mapping between Wikipedia and Wikidata through the [website](https://dumps.wikimedia.org/enwiki/), you can change the language to access to different mappings across countries. In our experiments, we use **'enwiki', 'frwiki', 'dewiki', 'zhwiki', 'arwiki', 'eswiki'**.

The mapping.ipynb provide the code to querying the sql file to a txt file, such as enwiki, where include the mapping information structured as **wikipediaID**, **WikidataID**, **the mapping language**.
